Tour creation

1. Add tour info

Title, place, description and status.

2. Upload media

Thumbnail and optional video or 360 URL.

3. Set location

Validate address and adjust coordinates.

Publication status

Use Draft while preparing the tour. Publish only after the scenes, hotspots and preview are ready.

After saving, open the Builder to add 360 scenes and hotspots.

Image quality

For best display on mobile and desktop, use a clean landscape thumbnail. The backend can generate optimized versions automatically.
